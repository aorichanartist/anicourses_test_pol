# АНИКУРСЫ — Политический тест

25 вопросов, варианты «скорее да / трудно ответить / скорее нет», четыре шкалы результатов, семь пастельных цветов, эпизодические реплики Крота.

Сайт открывается через GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Временная озвучка в этой публикации использует голос браузера (speechSynthesis). Авторские MP3 добавим отдельно.

Ответы сохраняются только в localStorage пользователя. Тест развлекательный, не научная диагностика и не политическая агитация.
